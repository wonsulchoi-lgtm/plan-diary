[ 나의 직무 기획 다이어리 — GitHub + Vercel 올리는 방법 ]

■ 1. GitHub에 파일 올리기
  저장소(github.com/wonsulchoi-lgtm/plan-diary) → Add file → Upload files
  'plan-diary_GitHub올릴파일' 폴더 안의 것을 모두 끌어다 놓고 Commit changes
    index.html      화면
    prompts.json    AI 프롬프트 모음
    api/ai.js       AI 연결 (Vercel 서버 함수) ※ api 폴더째로
    package.json    Claude SDK 설치 목록
    vercel.json     Vercel 설정 (함수 시간 120초)
    README.md       저장소 설명
    업로드_방법.txt  이 안내
    .gitignore      키 파일 등 제외 목록 (숨김 파일: Finder에서 Cmd+Shift+. 로 보임)

■ 2. Vercel 연결
  vercel.com → Continue with GitHub → Add New → Project → plan-diary Import → Deploy

■ 3. API 키 넣기 (코드에 넣지 않음!)
  Vercel 프로젝트 → Settings → Environment Variables
    Key: ANTHROPIC_API_KEY   Value: sk-ant-... (console.anthropic.com → API Keys)
  저장 후 Deployments → 맨 위 ⋯ → Redeploy

■ 모델
  기본 claude-sonnet-5-5. 바꾸려면 환경 변수 CLAUDE_MODEL 추가 (예: claude-opus-5-5)

■ 확인
  https://(프로젝트).vercel.app → 문제정의 장 '버기 심사위원에게 점검받기' 결과가 나오면 OK
  연습 모드(AI 안 부름): 주소 끝에 ?demo=1

■ 비용 보호
  console.anthropic.com → Settings → Limits 에서 월 사용 한도(Spend limit) 설정
  학생 1명당 AI 호출 5~8번(점검·원인·SCAMPER·KPI·기획서)
